## Deployment Setup Guide (fill in after Replit AI finishes)

### Backend → Render (Web Service)
| Setting | Value |
|---|---|
| Root Directory | `Point-Of-Sale-System/backend` |
| Build Command | `npm install && npm run build` |
| Start Command | `node dist/index.js` |
| Environment | Node |
| Env Vars | `DATABASE_URL`, `JWT_ACCESS_SECRET`, `JWT_REFRESH_SECRET`, `CORS_ORIGIN` (your Vercel URL), `PORT=3001` |

### Render PostgreSQL
1. Render Dashboard → New → PostgreSQL → note the **Internal Database URL**.
2. Set it as `DATABASE_URL` in the backend web service env vars.
3. After first deploy, run migrations: Render Shell → `npm run migrate` (or your migrate script) → then seed default users.
